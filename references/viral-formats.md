# Proven formats

Read when the brief names a format or the footage fits one. Each template is a beat structure for the paper edit (roles in brackets). Durations are STARTING DEFAULTS for a 30 s short; scale them for long-form.

| Format | Beats |
|---|---|
| **Tried it for N days** | [hook] the day-N result, 0-2 s -> [setup] day 1 and the rule, 2-6 s -> [body] 3-5 day montage with day counters, escalating -> [payoff] the honest result -> [ending] one-line verdict |
| **Before and after** | [hook] the after, or a split screen -> [setup] the before -> [body] 2-4 process steps -> [payoff] the full after reveal -> [ending] the loop back to the before |
| **Ranking / tier list** | [hook] the controversial pick ("X is S-tier?") -> [body] items from worst to best, one visual each -> [payoff] number 1 -> [ending] invite disagreement (honest, not bait) |
| **Things nobody tells you** | [hook] "Nobody tells you this about [x]" -> [body] 3 points, each a punch-in plus a callout -> [payoff] the most useful point, last -> [ending] no recap |
| **Story with a twist** | [hook] mid-action or stakes -> [setup] context in under 5 s -> [tension] the build -> [reveal] the twist (only if real) -> [ending] reaction, hold a beat |
| **Challenge with stakes** | [hook] the stake -> [setup] the rules -> [tension] attempts, escalating -> [payoff] success or failure -> [ending] the cost or reward |
| **Satisfying process** | [hook] the most satisfying frame -> [body] steps cut on beats, natural sounds up front -> [payoff] the finished result -> [ending] loop to the first frame |
| **Point of view** | [hook] "POV: [situation]" text over first-person footage -> [body] the situation unfolding -> [payoff] the relatable punchline |
| **Myth vs fact** | [hook] the myth stated as if true -> [payoff] "that's wrong" with a hit -> [body] the fact with evidence B-roll -> [ending] a one-line takeaway |
| **Reveal at the end** | [hook] promise the reveal -> [tension] escalating clues -> [reveal] the reveal. **Only with a real reveal**, and the hook must say what is coming. |

## Rules
- The format is structure only: never copy a trending video's content, words or assets.
- A format that does not fit the footage is worse than none. If the material is a single talking point, use the type's default structure (craft-story-structures.md).
- Record the chosen format in the paper edit's `opening` or `notes`.
